# Dungeon Explorer - Text-Based Exploration and Combat Game

A console-based program that guides the player through a dungeon using a stylised ASCII map.

You are able to:
- Manage an inventory
- Equip items as you choose
- Affect the environment based on the currently-equipped item
- Navigate around the dungeon/map freely (you may return to a previously-visited area)
- Use items collected to aid you in battle
- Battle 2 enemies with varying stats
  - Interact with the battle by timing your hit on the enemy
  - Enhance your attack (base damage/crit rate/crit damage) with the selected weapon
  - Defend yourself with the selected bonus item

<br>

Used **C# in Visual Studio** with the **.Net framework**.

Project was an assignment for a module called **Object-Oriented Programming**.
